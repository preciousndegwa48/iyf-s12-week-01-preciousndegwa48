## Project Description
First portfolio built for IYF S12 Week 01. Includes accessible index.html, semantic HTML conversion, accessible contact form with labels and fieldsets, and WCAG accessibility audit. Built entirely on phone and deployed on GitHub Pages.

## Technologies Used
- HTML5
- GitHub Pages
- Lighthouse & WAVE

## Features
- Accessible index.html
- Semantic HTML conversion
- Accessible contact form
- Accessibility audit report (100/100)

## How to Run
1. Clone: `git clone https://github.com/preciousndegwa48/iyf-s12-week-01-preciousndegwa48.git`
2. Open `index.html` in browser

## Lessons Learned
Semantic HTML, alt text, heading hierarchy, label associations, GitHub Pages deployment from mobile, Lighthouse audit.

## Challenges Faced
GitHub "Its not empty" error fixed via mobile web flow, phone-only coding, and learning proper form accessibility structure.
